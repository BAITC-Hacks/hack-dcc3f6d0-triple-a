# AI Sana

Демонстрационный MVP на Python + Streamlit. Внешние API и база данных не требуются.

## Запуск

Требуется Python 3.10 или новее.

```shell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Демонстрация

1. На главной нажмите «Создать задачу» и заполните основные поля.
2. Нажмите «Оценить качество задачи». Оценка учитывает заполненность и длину текста, а не его смысл. Веса полей находятся в `utils.py`.
3. Нажмите «Улучшить задачу», уточните описание и повторно оцените карточку. Все поля сохраняются.
4. При рейтинге от 75 и заполнении всех основных полей опубликуйте задачу.
5. Найдите её в каталоге, откройте «Подробнее» и нажмите «Откликнуться».
6. Отправьте предложение команды. Можно добавить вторую команду для демонстрации выбора.
7. Откройте «Отклики для бизнеса», выберите задачу и нужную команду. Остальные предложения получают статус «Не выбрана»; приём новых предложений закрывается.

Каталог изначально содержит три примера с фиксированными демонстрационными рейтингами. Новые задачи получают локально рассчитанный рейтинг. По умолчанию самые высокие оценки показываются первыми.

Роли переключаются навигацией без авторизации. Все данные находятся в `st.session_state`, доступны только в одной браузерной сессии и не являются общим хранилищем между пользователями. Для показа жюри проходите весь сценарий в одной вкладке. Перезагрузка вкладки или остановка сервера может сбросить данные.

## Файлы

- `app.py` — экраны, навигация, стили и состояние интерфейса.
- `utils.py` — локальная оценка, демоданные, публикация и обработка предложений.
- `.streamlit/config.toml` — тема и параметры запуска.
- `requirements.txt` — единственная зависимость: Streamlit.
